Invest Quest

Simulador educativo de inversiones con mecánicas de gamificación, mercado ficticio, lecciones interactivas y funciones asistidas por IA para aprender finanzas de forma práctica y segura.

Objetivo general

Brindar una experiencia de aprendizaje sobre inversiones que combine teoría, práctica y motivación lúdica, permitiendo que cada usuario explore decisiones financieras sin usar dinero real.

Simulación de mercado Aprendizaje guiado XP, misiones y ranking Coach IA configurable Experiencia responsive

MVP demostrativo — sin autenticación productiva ni datos financieros reales.

Visión funcional

Descripción funcional del sistema

Resumen del problema que aborda InvestQuest y del valor que entrega a sus usuarios principales.

Qué problema resuelve

Muchas personas quieren aprender a invertir, pero encuentran barreras de entrada como lenguaje técnico, miedo a perder dinero y falta de acompañamiento personalizado. InvestQuest aborda este problema mediante un entorno de práctica controlado y educativo.

Para qué sirve

Sirve para simular operaciones financieras, comprender tipos de activos, reforzar conceptos mediante lecciones y quizzes, medir progreso con XP y recibir orientación educativa usando modelos de IA configurables.

Usuarios principales

  • Personas principiantes que quieren iniciarse en inversiones.
  • Usuarios que aprenden mejor con práctica y gamificación.
  • Docentes, tutores o equipos que necesiten una demo educativa fintech.
Capacidades

Módulos y funcionalidades principales

Inventario funcional basado en pantallas, acciones del servidor, modelos de base de datos y endpoints disponibles.

Registro / login

No implementado como autenticación real. El sistema actual trabaja en modo demo. El “usuario activo” se selecciona desde un switcher en la interfaz y se guarda en una cookie iq-user-id.

En la documentación académica o profesional conviene aclarar que este punto se encuentra reemplazado por selección de usuarios demo, no por registro ni login tradicionales.

Dashboard principal

Resume el estado del usuario: valor total del portfolio, efectivo disponible, capital invertido, ganancia o pérdida, nivel, XP acumulada, progreso hacia el siguiente nivel y misión sugerida.

  • Vista resumen de cartera.
  • Accesos rápidos al simulador y al coach.
  • Notificación para configurar IA si todavía no existe proveedor asociado.

Gestión de inversiones / simulador

Es el núcleo operativo del sistema. Permite comprar y vender activos ficticios usando saldo virtual, calcular holdings, registrar transacciones y mostrar variación de precios simulados.

  • Activos disponibles: acciones, ETFs, bonos y cripto.
  • Validación de fondos y tenencias antes de operar.
  • Actualización periódica de precios mediante ticks de mercado.
  • Impacto en misiones, badges y XP.

Aprendizaje y lecciones

Módulo que carga contenido educativo desde archivos Markdown dentro del proyecto. Cada lección puede incluir cuestionario, revisión de respuestas y recompensa en XP al completarla.

  • Lecciones categorizadas por tema.
  • Visualización en modal.
  • Quiz interactivo con porcentaje mínimo de aprobación.
  • Persistencia de lecciones completadas como misiones.

Coach IA

Chat educativo que utiliza un proveedor de IA configurado por el propio usuario. Responde en función del estado del portfolio, del nivel, del XP y del perfil de riesgo registrado.

  • Historial persistido en base de datos.
  • Prompts rápidos sugeridos.
  • Soporte para OpenAI, Anthropic y Google.
  • Mensajería orientada a fines educativos, no asesoramiento real.

Perfil de usuario y ajustes

Centraliza configuración de IA, selección de modelo, almacenamiento cifrado de API key, test de perfil de riesgo asistido por IA y reinicio total del progreso del usuario.

  • Proveedor y modelo configurables.
  • Prueba de conexión al servicio IA.
  • Clasificación de perfil: conservador, moderado o agresivo.
  • Zona peligrosa para resetear datos demo.

Ranking y gamificación

Compara a los usuarios demo por experiencia acumulada y por rendimiento de cartera. Complementa la lógica de misiones, niveles y badges para reforzar el aprendizaje por objetivos.

  • Ranking por XP.
  • Ranking por retorno porcentual.
  • Niveles calculados desde XP.
  • Badges por hitos como primera operación o diversificación.
Diseño técnico

Arquitectura del sistema

Descripción de capas, persistencia y flujos de comunicación internos.

Frontend Next.js App Router Pantallas server-side y componentes client-side para dashboard, simulador, aprendizaje, ranking, coach y ajustes.
Lógica de negocio Server actions + librerías internas Operaciones de trading, cálculo de portfolio, XP, misiones, badges, perfil de riesgo y cifrado.
Persistencia Prisma + SQLite Guarda usuarios, activos, ticks de precios, holdings, transacciones, misiones, badges, mensajes y settings.
Servicios externos Proveedores IA Integración opcional con OpenAI, Anthropic y Google vía Vercel AI SDK y API keys del usuario.

Frontend

  • Basado en Next.js 16 con App Router.
  • Uso de componentes de interfaz con shadcn/ui y Radix.
  • Estado del usuario demo manejado en cliente con Zustand.
  • Diseño responsive con Tailwind CSS v4.
  • Navegación adaptativa con sidebar en escritorio y barra inferior en mobile.

Backend

  • Endpoints internos en src/app/api.
  • Server actions para acciones sensibles como trading o guardado de proveedor IA.
  • Lógica de dominio separada en src/lib.
  • Validación de entradas con Zod.

Base de datos

Se usa SQLite como motor local, gestionado mediante Prisma ORM. El esquema actual incluye las entidades principales del producto:

User Asset PriceTick Holding Transaction Mission Badge ChatMessage AppSetting

APIs externas

  • OpenAI: modelos gpt-4o-mini y gpt-4o.
  • Anthropic: modelos claude-haiku-4-5 y claude-sonnet-4-6.
  • Google: modelos gemini-2.5-flash y gemini-2.5-pro.

No se detectaron integraciones con brokers reales ni proveedores de market data reales.

Flujo general de comunicación

1. Interacción del usuario La interfaz de Next.js presenta pantallas y formularios para operar, aprender, chatear o configurar preferencias.
2. Envío a server action o endpoint Según el caso, la UI llama a una server action o realiza un fetch a rutas internas /api.
3. Validación y lógica El backend valida entradas con Zod y ejecuta reglas de negocio: trading, awarding XP, cálculo de portfolio, clasificación o prompts de IA.
4. Persistencia Prisma actualiza SQLite con holdings, transacciones, mensajes, progreso y configuraciones.
5. Respuesta a UI El frontend muestra el nuevo estado mediante refresco, re-render, toasts o actualización local.

Tecnologías utilizadas

Relación de herramientas efectivamente presentes en el proyecto.

Frameworks y entorno principal

  • Next.js 16.2.4 para frontend y backend unificados.
  • React 19 para la construcción de interfaces.
  • TypeScript 5 para tipado estático.

Interfaz y experiencia de usuario

  • Tailwind CSS v4 para estilos utilitarios.
  • Radix UI y componentes base shadcn/ui.
  • Lucide React para iconografía.
  • Sonner para notificaciones toast.
  • Recharts disponible para visualizaciones.

Datos, validación y estado

  • Prisma ORM como capa de acceso a datos.
  • SQLite como base local.
  • Zod para validación de inputs.
  • Zustand para manejo de estado del usuario actual.

Contenido y funciones auxiliares

  • gray-matter para parsear frontmatter de lecciones Markdown.
  • react-markdown para renderizar contenido educativo.
  • date-fns y utilidades menores de formateo.

IA y modelos

  • Vercel AI SDK mediante el paquete ai.
  • @ai-sdk/openai.
  • @ai-sdk/anthropic.
  • @ai-sdk/google.

Herramientas de desarrollo

  • ESLint para calidad de código.
  • tsx para ejecutar scripts TypeScript como el seed.
  • Prisma Migrate para migraciones.
  • npm como gestor de paquetes y scripts.

Calidad técnica

Consideraciones técnicas

Puntos relevantes sobre robustez, validaciones, seguridad y límites del MVP.

Validaciones

  • Las entradas de endpoints y server actions se validan con Zod.
  • Trading valida existencia de usuario, activo, fondos y tenencias.
  • Coach y perfil validan estructura del body antes de operar.
  • Las preguntas del test de riesgo requieren respuestas completas.

Seguridad

  • Las API keys de IA se almacenan cifradas con AES-GCM usando APP_SECRET.
  • El propio código aclara que este cifrado es MVP-grade y no una solución productiva definitiva.
  • No hay autenticación robusta ni autorización por sesión real.
  • El patrón de cookie de usuario demo no es apto para producción.

Manejo de errores

  • Existen páginas de error global y del dashboard.
  • Los endpoints devuelven códigos 400, 404, 422 o 500 según corresponda.
  • La interfaz informa fallos mediante toasts.
  • El motor de mercado y las funciones IA registran errores en consola.

Persistencia de datos

  • Usuarios, holdings, transacciones, ticks, misiones, badges y chats se persisten en SQLite.
  • El progreso puede reiniciarse completamente desde ajustes.
  • Las lecciones se almacenan en archivos, no en base de datos.
  • El estado del usuario actual se conserva además del lado cliente.
Dato importante para presentación
InvestQuest está claramente orientado a demostración educativa. No opera con dinero real, no brinda asesoramiento financiero real y no implementa autenticación productiva.
Límite técnico actual
La app usa precios simulados y base SQLite local. Para un entorno multiusuario real haría falta infraestructura, seguridad y observabilidad más avanzadas.
Roadmap sugerido

Posibles mejoras futuras

Ideas alineadas con el estado actual del código y con una evolución razonable del producto.

Mejoras funcionales

  • Agregar autenticación real con registro, login y recuperación de cuenta.
  • Incorporar feed de noticias o señales financieras educativas.
  • Exponer en UI las misiones personalizadas y el feedback IA detectados en los endpoints.
  • Agregar historial avanzado de operaciones y reportes descargables.

Mejoras visuales

  • Profundizar dashboards con más gráficos comparativos.
  • Mostrar timelines de rendimiento por activo.
  • Agregar onboarding visual para primer ingreso.
  • Mejorar accesibilidad, contraste, estados vacíos ilustrados y optimización fina para pantallas pequeñas.

Mejoras técnicas

  • Migrar a una base de datos más robusta para producción.
  • Implementar testing automatizado end-to-end y unitario.
  • Usar un vault o KMS para secretos en lugar de cifrado local MVP.
  • Agregar observabilidad, logs estructurados y control de errores más fino.
Cierre

Conclusión

Síntesis final del valor del sistema y del estado actual del proyecto.

InvestQuest es un MVP educativo que combina simulación de inversiones, gamificación e IA configurable para enseñar finanzas sin riesgo real. Muestra una arquitectura moderna con separación clara de responsabilidades, dejando explícitos sus límites actuales: modo demo, autenticación no productiva y datos simulados. Es una base sólida para validar la propuesta de producto y escalar en futuras etapas.
